# Երգ Ալբոմ Ժանր Տևողություն

    Այստեղ դատարկ է

    Ավելացրու երգեր songs.json ֆայլում կամ սեղմիր «Ավելացնել ֆայլեր»։

    Կարող ես նաև երաժշտական ֆայլերը քաշել ու թողնել այս պատուհանում։

    Քնի ժամաչափ

    Նվագարկումը կդադարի ընտրված ժամանակից հետո։

    Ցանկը չբեռնվեց

    Դիտարկիչը արգելում է file:// հասցեով JSON կարդալը։ Գործարկիր տեղային սերվերը կամ ընտրիր songs.json-ը ձեռքով։

    Սերվերը գործարկելու համար՝ Windows-ում կրկնակի սեղմիր start-windows.bat, macOS/Linux-ում՝ start-mac-linux.sh։
